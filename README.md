# DigiShelf – how to use the admin panel

1. Upload everything in this folder to your GitHub repo (replace the old files).
2. Create a token: GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens.
   Repository access: only `Digital-products`. Permission: Contents = Read and write.
3. Open https://marketer-raja.github.io/Digital-products/admin.html, enter the token, sign in.
4. Icons tab: rename, re-link, reorder, hide, change the picture, or add icons.
5. Products tab: add e-books, trackers, templates etc. E-books show under "My E-books" on the homepage.
6. Click "Publish to website". The site updates in 1-2 minutes.

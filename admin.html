DigiShelf Admin

Sign in with your GitHub access token to manage the icons and products on your website. Only someone with the token can publish.

Create a fine-grained token at GitHub → Settings → Developer settings → Personal access tokens, limited to this one repository with Contents: Read and write.

Homepage icons

Each icon on the homepage links to its own page (category.html?cat=…) listing the products you publish in it. Leave the link blank to use that page, or paste any custom link. Untick “Published” to hide an icon.

Products

E-books marked Published appear in “My E-books” below Top Picks on the homepage. Every published product also appears on its icon’s page.
